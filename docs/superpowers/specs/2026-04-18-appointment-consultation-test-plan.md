# 測試計畫：預約系統 + 諮詢系統

**版本**: 1.1 (QA 審查後修訂)  
**日期**: 2026-04-18  
**環境**: renewT (`https://medicare.tomting.com/aesthetics/#/`)  
**測試帳號**: renewAdmin / renewAdmin  
**測試工具**: Playwright (Python, headless Chromium)

---

## 優先級定義

| 級別 | 意義 |
|------|------|
| **P0** | 核心路徑，失敗即阻斷 — 必須 100% 通過 |
| **P1** | 重要功能，影響日常使用 |
| **P2** | 邊界案例與進階功能 |

## 測試資料策略

- 每個測試用唯一名稱（`測試_YYYYMMDDHHMMSS_<seq>` 格式），避免跨執行衝突
- **測試間依賴**: APT-007 顯式依賴 APT-001 建立的預約；若 APT-001 失敗則 APT-007 標記 SKIP
- **不清理資料**：renewT 為測試環境，資料累積不影響功能驗證；計數類測試（CON-031）用相對斷言，不用絕對數字
